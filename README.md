# Canby Community Clinic

Complete multipage adaptation of the supplied template and Archive.zip. The supplied MP4 remains the homepage hero.

## Local preview

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Publish `dist/` to a static host. Content and common navigation are generated by `scripts/pages.mjs`; change `scripts/home.html` for homepage content, `scripts/content.mjs` for care pages, and `src/styles/` for styling. `npm run build` regenerates the pages.

## Included pages

Home, Services, Appointments, New patients, Resources, Visit, Our clinic, Volunteer, Donate, Request a visit, Accessibility, Nondiscrimination, Privacy, Notice of privacy practices, Emergency information, and a not-found page.

## Forms and donations

Callback, appointment, and volunteer forms validate required fields and prepare an email draft to office@canbycc.org. The public address shown on every page is info@canbycc.org. The visitor opens and sends the draft. The website does not submit or store form entries. A copyable message is available when no email app is configured.

The donation page is deliberately in demo mode, as requested. It supports preset/custom USD amounts, one-time/monthly giving, Card/PayPal preview selection, and a demo receipt. It does not request card details or charge money. To enable live giving, connect approved hosted checkout links or a server-created checkout session; only a confirmed provider response should show an actual donation receipt. Do not place payment secrets in frontend code. No payment account is currently connected.

## Old URLs

`scripts/redirects.json` records old-to-new destinations. It includes the archive’s `/CanbyCLinic-Admin/` base path and all archived deep links, plus the template’s About, Contact, FAQ, Articles, Events, Stories, and old legal URLs. Query strings and fragments are retained in the static redirect documents.

- Local development: HTTP 301 redirects through Vite middleware.
- Netlify-compatible hosting: `dist/_redirects` provides permanent redirects.
- Vercel: `vercel.json` supplies permanent redirects and route handling.
- Other static hosts: built legacy HTML pages redirect in-browser, with a clickable fallback. Configure HTTP 301 rules from the mapping if the host supports them.

These rules operate on the domain where this build is deployed. Redirecting a separate old domain requires access to that domain’s hosting settings.
